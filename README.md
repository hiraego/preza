# Известные зарубежные экологи: презентация

Презентация к реферату Аладько И. И. (ИТМО, факультет экотехнологий, 2026). 44 слайда на выступление 7-9 минут.

## Готовые файлы

| Файл | Что это |
|---|---|
| `dist/Аладько_Известные_зарубежные_экологи.pdf` | PDF, каждая страница это картинка 2560×1440. Живого текста и шрифтов нет, ничего не поплывет |
| `dist/Аладько_Известные_зарубежные_экологи.pptx` | PPTX 16:9, каждый слайд это та же картинка на весь слайд. В заметках к слайдам готовый текст выступления (~1100 слов) |

## Как устроено

Слайды сверстаны в HTML/CSS и сняты браузером в картинки, поэтому PDF и PPTX выглядят одинаково на любом компьютере.

```
src/deck.html        все 44 слайда + заметки докладчика (<aside class="notes">)
src/deck.css         дизайн-система: шрифты, цвета частей, компоненты
src/deck.js          футер со шкалой времени, подписи к 3D, графики (d3)
src/3d/scenes/*.js   3D-сцены на three.js (Чимборасо, глобус, бочка Либиха, пирамида Элтона, экосистема, пруд, острова)
assets/render3d/     готовые рендеры 3D-сцен (PNG с прозрачным фоном) + координаты подписей
assets/photos/       фото с Wikimedia Commons, лицензии в CATALOG.md и meta/
assets/data/         данные для графиков (заяц и рысь, годы жизни, долгожители)
scripts/             рендер и сборка PDF/PPTX
```

Части доклада различаются «материалом»: XIX век на бумаге с гравюрами Геккеля, «Считать» в виде чертежа, «Предупреждать» в черно-красной гамме, «Вся планета» на фоне космоса. Внизу каждого слайда шкала 1770-2025 с отметкой года.

## Сборка

Нужны Node 18+, Python 3, Chromium для Playwright.

```bash
npm install
pip install img2pdf python-pptx
node scripts/render3d.mjs        # 3D-сцены (нужно только если меняли src/3d)
node scripts/render.mjs          # слайды -> build/jpg/*.jpg
python3 scripts/build_outputs.py # build/jpg -> dist/*.pdf, dist/*.pptx
```

Быстрый просмотр: `node scripts/render.mjs --fast 7 12` кладет PNG выбранных слайдов в `build/slides/`. Посмотреть все слайды в браузере: `node scripts/serve.mjs` и открыть `http://127.0.0.1:8123/src/deck.html`.

## Правила текста

На слайдах и в заметках нет тире и буквы «ё», дефис только в диапазонах лет и внутри слов. Факты и цифры взяты из реферата.
