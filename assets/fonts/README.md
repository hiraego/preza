# Шрифты

Все шрифты под лицензией SIL Open Font License 1.1 (Google Fonts):

- Inter Tight (Rasmus Andersson) — заголовки и текст
- Spectral (Production Type) — цитаты, курсив
- IBM Plex Mono (IBM) — подписи и метки

У Inter Tight метрики `usWinAscent/usWinDescent` выровнены по `hhea/typo`, чтобы высота строки
совпадала в браузере, PowerPoint и LibreOffice. Эти же файлы встраиваются в PPTX.
