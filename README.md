# Известные зарубежные экологи: презентация

Презентация к реферату Аладько И. И. (ИТМО, факультет экотехнологий, 2026). 44 слайда на выступление 7-9 минут.

## Готовые файлы

| Файл | Что это |
|---|---|
| `dist/Аладько_Известные_зарубежные_экологи.pdf` | PDF, каждая страница это картинка 2560×1440. Живого текста и шрифтов нет, ничего не поплывет |
| `dist/Аладько_Известные_зарубежные_экологи.pptx` | Настоящий PPTX: весь текст редактируемыми текстовыми полями, фото, 3D и графики отдельными картинками, шрифты встроены в файл, в заметках к слайдам текст выступления (~1100 слов) |

## Оформление

- Шрифты: Inter Tight (заголовки и текст), Spectral Italic (цитаты), IBM Plex Mono (подписи). Лежат в `assets/fonts`, лицензия SIL OFL.
- Четыре части доклада, четыре цвета: I «Описывать» еловый зеленый, II «Считать» кобальт на миллиметровке, III «Предупреждать» сигнальный красный, IV «Вся планета» янтарный на черном.
- Без скруглений и «пилюль»: прямые линии, линейки, плоские цветные поля, архивные фото в ч/б.
- Внизу каждого слайда шкала 1770-2025 с отметкой года.

## Как устроено

Слайды сверстаны в HTML/CSS. PDF получается скриншотами слайдов. PPTX собирается из той же верстки: каждый блок слайда становится либо картинкой (графика), либо текстовым полем с теми же переносами строк, шрифтом, размером и цветом.

```
src/deck.html        все 44 слайда + заметки докладчика (<aside class="notes">)
src/deck.css         дизайн-система
src/deck.js          футер со шкалой времени, подписи к 3D, графики (d3), подстановка портретов
src/3d/scenes/*.js   3D-сцены на three.js (Чимборасо, глобус, бочка Либиха, пирамида Элтона, экосистема, пруд, острова)
assets/render3d/     готовые рендеры 3D-сцен + координаты подписей
assets/photos/       фото с Wikimedia Commons, лицензии в CATALOG.md и meta/
assets/fonts/        шрифты (они же встраиваются в PPTX)
scripts/             рендер и сборка PDF/PPTX
```

## Сборка

Нужны Node 18+, Python 3 (`pip install img2pdf python-pptx fonttools pillow lxml`), Chromium для Playwright.

```bash
npm install
npm run render3d   # 3D-сцены (только если меняли src/3d)
npm run build      # dist/*.pdf и dist/*.pptx
```

По отдельности: `npm run pdf`, `npm run pptx`. Быстрый просмотр: `node scripts/render.mjs --fast 7 12` кладет PNG выбранных слайдов в `build/slides/`. Все слайды в браузере: `npm run serve` и открыть `http://127.0.0.1:8123/src/deck.html`.

## Правила текста

На слайдах и в заметках нет тире и буквы «ё», дефис только в диапазонах лет и внутри слов. Факты и цифры взяты из реферата.
